# Розділ 10. Аналіз системи безпеки

Забезпечення безпеки інформаційної системи табельного обліку базується на комплексному підході, що охоплює захист даних на рівні мережі, застосунку та бази даних.

### 1. Автентифікація та авторизація
* **Механізм доступу:** Використання протоколу OAuth 2.1 та JWT (JSON Web Tokens) для авторизації запитів. Токени мають обмежений термін дії, що мінімізує ризики у разі їх перехоплення.
* **Рольова модель (RBAC):** Доступ до даних суворо розмежований за ролями (Employee, Manager, HR, Admin). Кожен рівень має доступ лише до тих ресурсів, які необхідні для виконання посадових обов'язків.

### 2. Захист передачі та зберігання даних
* **Шифрування трафіку:** Усі з'єднання між клієнтом (веб-інтерфейс, мобільний додаток) та сервером здійснюються через протокол HTTPS із використанням сертифікатів TLS 1.3.
* **Хешування паролів:** Паролі користувачів зберігаються в базі даних у зашифрованому вигляді з використанням алгоритму Argon2 або bcrypt із додаванням «солі».

### 3. Аудит та моніторинг
* **Журналювання подій:** Система фіксує всі критичні дії (вхід у систему, зміна записів табеля, видалення акаунтів) із зазначенням ID користувача та часу дії.
* **Захист від перебору (Rate Limiting):** Обмеження кількості запитів з однієї IP-адреси для запобігання Brute-force атакам та DDoS-навантаженню на API.

### 4. Фізична та мережева безпека
* Використання mTLS (Mutual TLS) для інтеграції з фізичними пристроями (турнікетами) та обмеження доступу до бази даних лише для внутрішньої мережі (IP Whitelisting).
