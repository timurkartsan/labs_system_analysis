# Розділ 2. Збір і аналіз вимог

Основні вимоги до системи базуються на наступних принципах та потребах:

* **Швидкість і простота:** 1–2 кліки до ключових дій (чек-ін/чек-аут, погодження заявок).
* **Консистентність:** єдині патерни форм, фільтрів, таблиць, кнопок і повідомлень.
* **Видимість станів:** чіткі індикатори "в роботі/поза роботою", статуси заявок/змін.
* **Доступність:** контраст ≥ 4.5:1, повна клавіатурна навігація, мобільність (критичні сценарії оптимізовані для мобільних пристроїв).
* **Толерантність до помилок:** інформативні повідомлення, автозбереження чернеток.
* **Надійність та продуктивність:** ACID транзакції для критичних даних про робочий час, Redis кешування, Connection pooling для бази даних.
* **Безпека:** HTTPS для всіх з'єднань, шифрування паролів, аудит логи для відслідковування дій.
