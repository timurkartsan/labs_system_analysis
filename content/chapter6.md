# Розділ 6. Архітектура системи та залежності між підсистемами

## 1. Логічна архітектура
Система побудована за принципом трирівневої архітектури:
* **Рівень представлення:** Веб-інтерфейс (React/Vue.js), Мобільний додаток (чек-ін/чек-аут), REST API для інтеграцій, Адміністративна панель.
* **Рівень бізнес-логіки:** Сервіс автентифікації та авторизації (Auth Service), Сервіс табельного обліку (Attendance Service), Сервіс управління відпустками (Leave Service), Сервіс звітності (Report Service).
* **Рівень даних:** PostgreSQL (основна БД), Redis (кеш для сесій), Файлове сховище документів.

## 2. Фізична архітектура
* **Веб-сервер:** Nginx з балансуванням навантаження.
* **Сервери додатків:** Node.js в Docker контейнерах.
* **Бази даних:** PostgreSQL з реплікацією, Redis.

## 3. Залежності та взаємодія підсистем
Компоненти взаємодіють через REST API. 
* **Зовнішні інтеграції:** Турнікети та пристрої контролю доступу (MQTT/HTTPS), Email сервери для нотифікацій, HR системи (SAP/BambooHR) через REST API.
